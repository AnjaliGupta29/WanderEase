# WanderEase

WanderEase is a full-stack web application that replicates the core functionalities of Airbnb. It allows users to browse, book, and list accommodations worldwide, providing a seamless and user-friendly experience for travelers and hosts.

## Features

### 🏡 For Guests
- **Search & Explore**: Browse accommodations based on location, price, and amenities.
- **Booking System**: Securely book stays with real-time availability.
- **Reviews & Ratings**: Leave and read reviews from previous guests.
- **Wishlist**: Save favorite listings for future reference.
- **User Authentication**: Sign up and log in securely with email/password or social login.

### 🏠 For Hosts
- **List a Property**: Easily add new listings with images, descriptions, and pricing.
- **Manage Bookings**: Accept or reject bookings from guests.
- **Calendar Integration**: Set availability and block out dates.
- **Earnings Dashboard**: Track revenue and upcoming payouts.

### 🛠️ Admin Features
- **User Management**: View and manage user accounts.
- **Property Moderation**: Approve or flag listings for quality control.
- **Analytics Dashboard**: Monitor platform usage and trends.

## Tech Stack

- **Frontend**: JavaScipt, Tailwind CSS
- **Backend**: Node.js, EJS
- **Database**: MongoDB

## Installation & Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/Anjaligupta29/WanderEase.git
   cd wanderease
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Set up environment variables (`.env` file):
   ```sh
   DATABASE_URL=your_database_url
   ```
4. Run the development server:
   ```sh
   npm start
   ```
5. Open your browser and navigate to `http://localhost:3000`
